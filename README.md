# csc649-week4-lab

days_left: Calculates the number of days remaining until a due date, returning a negative value if the task is overdue.

is_urgent: Checks whether a task is due within a specified number of days without being already overdue.

sort_by_due: Returns a new list of task dictionaries ordered chronologically by their due date.

completion_rate: Calculates the percentage of completed tasks rounded to one decimal place, returning 0.0 if there are no tasks.
